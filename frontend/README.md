# Smart Camera Surveillance System - Frontend

نظام مراقبة ذكي متقدم بواجهة مستخدم حديثة وجذابة بناء بـ React و TypeScript.

## المميزات الرئيسية

### 📷 إدارة الكاميرات
- إضافة وإدارة الكاميرات المتعددة
- عرض البث المباشر
- تجميع الكاميرات في مجموعات منطقية
- إدارة إعدادات كل كاميرا

### 🎯 التعرف الذكي
- التعرف على الوجوه والأشخاص
- إدارة قاعدة بيانات الأشخاص
- تحديد أفراد المنزل والزوار والغرباء

### 🚨 نظام التنبيهات الذكي
- تنبيهات فورية للأحداث الحساسة
- تصنيف التنبيهات حسب الأولوية
- إمكانية تأكيد وحل التنبيهات

### 🚔 كشف السرقات والاقتحام
- كشف الحركات المريبة
- كشف محاولات السرقة
- كشف الاقتحام غير المصرح

### 📊 التحليلات والإحصائيات
- إحصائيات الكشفيات
- رسوم بيانية للأنشطة
- تقارير يومية وأسبوعية وشهرية

### 💾 إدارة التسجيلات
- تسجيل مستمر أو بناءً على الحركة
- بحث عن التسجيلات
- حذف التسجيلات القديمة تلقائياً

### 🎨 واجهة المستخدم
- تصميم عصري وجذاب
- دعم اللساني العربي الكامل
- RTL (Right-to-Left) محسّنة
- تجاوب كامل على جميع الأجهزة

## البنية المعيارية

```
src/
├── components/          # المكونات المعيارية
│   ├── Common/         # مكونات عامة (Button, Card, etc)
│   ├── Camera/         # مكونات الكاميرات
│   ├── Alert/          # مكونات التنبيهات
│   ├── Detection/      # مكونات الكشفيات
│   ├── Layout/         # مكونات التخطيط
│   └── Dashboard/      # مكونات لوحة المراقبة
├── pages/              # صفحات التطبيق
├── hooks/              # React Hooks مخصصة
├── store/              # إدارة الحالة (Zustand)
├── services/           # الخدمات والـ API
├── utils/              # الدوال المساعدة
├── types/              # تعريفات TypeScript
├── assets/             # الصور والموارد
└── styles/             # الأنماط العامة
```

## البدء السريع

### المتطلبات
- Node.js 16+ و npm/yarn
- معرفة أساسية بـ React و TypeScript

```bash

```

- **Tailwind CSS**: إطار عمل للأنماط
- **Zustand**: إدارة الحالة
- **Axios**: مكتبة HTTP

### UI Components
- مكونات جاهزة وقابلة للتخصيص
- عناصر تحكم حديثة
- حالات تحميل وطلب

## المكونات الرئيسية

### Common Components
- `Button`: زر قابل للتخصيص
- `Card`: بطاقة محتوى
- `Modal`: نافذة منفثقة
- `Badge`: شارة
- `Input`: حقل إدخال
- `Select`: قائمة اختيار
- `StatusIndicator`: مؤشر حالة

### Hooks المخصصة
- `usePolling`: تحديث دوري
- `useDebounce`: تأخير الاستدعاء
- `usePagination`: تقسيم الصفحات
- `useCamera`: التحكم بالكاميرا
- `useFileReader`: قراءة الملفات

## إدارة الحالة

استخدام **Zustand** لإدارة الحالة المركزية:

```typescript
import useDashboardStore from '@store/dashboardStore';

const { cameras, alerts, fetchCameras } = useDashboardStore();
```

## الخدمات (API)

جميع استدعاءات API موحدة في `ApiService`:

```typescript
import { apiService } from '@services/api';

// جلب الكاميرات
const cameras = await apiService.getCameras();

// إضافة كاميرا
const newCamera = await apiService.createCamera(cameraData);
```
